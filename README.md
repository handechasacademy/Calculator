# Vanilla JS Calculator

![CI](https://github.com/handechasacademy/Calculator/actions/workflows/ci.yml/badge.svg)

A vanilla JavaScript calculator project with CI/CD via GitHub Actions.

## Features
- Simple calculator UI using HTML, CSS, and JavaScript
- Automatic tests with Jest (`calculator.test.js`)
- Code linting with ESLint (`eslint.config.mjs`)
- CI/CD pipeline with GitHub Actions (lint + test on push/PR to `main` and `dev` branches)
- Error handling (division by zero, invalid input)

## Getting Started

### Prerequisites
- Node.js v20+
- npm

### Install Dependencies
```bash
npm install
